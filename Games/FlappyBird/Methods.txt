4. High Score Using Browser Cookies

Implement persistent high-score functionality using browser cookies.

Requirements:

Store the highest score in a cookie named flappyBirdHighScore.
Set a suitable cookie expiration period, such as 365 days.
Retrieve the cookie when the game loads.
Display the saved high score on the start screen and gameplay screen.
Update the cookie only when the current score exceeds the existing high score.
Ensure the saved score remains available after refreshing or reopening the browser.
Handle missing, invalid, or expired cookies gracefully.
Implement reusable JavaScript functions:
getHighScore()
saveHighScore(score)
updateHighScore(score)

Example cookie implementation:

javascript
function saveHighScore(score) {
    document.cookie =
        `flappyBirdHighScore=${score}; max-age=31536000; path=/; SameSite=Lax`;
}

function getHighScore() {
    const match = document.cookie.match(
        /(?:^|; )flappyBirdHighScore=(\d+)/
    );
    return match ? parseInt(match[1], 10) : 0;
}
